# Default TalkJS theme

The default theme for the TalkJS chat. Currently four formats are available:

- `react-jsx` - Use if you're writing a React app with JavaScript
- `react-tsx` - Use if you're writing a React app with TypeScript
- `web-js` - Use if you're using another framework, or just writing plain JavaScript
- `web-ts` - Use if you're using another framework, or just writing plain JavaScript
